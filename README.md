# CAP455-SMART-HOME-ENERGY-METER-PROJECT
A C++ console-based project that calculates electricity consumption and generates electricity bills based on appliance wattage, usage hours, and electricity rates. It also stores billing records using file handling.

Features

Calculate electricity consumption of appliances.

Convert Watts into Kilowatts using an inline function.

Calculate electricity units (kWh).

Generate electricity bills.

Store and read billing history using file handling.

Implement Object-Oriented Programming concepts.

Use constructors, destructors, and operator overloading.

Electricity Consumption Formula

Energy Consumption (Units):

Units (kWh) = (Wattage × Hours Used × Days) / 1000

Bill Calculation:

Bill Amount = Units Consumed × Rate per Unit
